# CleverNext storefront

Responsive static storefront foundation for CleverNext's Nigerian home and lifestyle essentials.

## Run locally
Open `index.html` in a browser or serve the repository root with any static server. No build step is required.

## Included
- Responsive landing page and mobile navigation
- Six local product-demonstration videos in a muted, inline hero sequence with pause control and reduced-motion support
- Product catalogue using supplied product imagery, category filters, sorting and search
- Product enquiries, FAQs and brand story

## Required before taking orders
No verified product prices, stock feed, delivery fees/coverage, official WhatsApp number, bank details, or order backend are present in this repository. These have not been invented. Product cards therefore show **Price on request** and the enquiry interaction is not an order or payment confirmation.

Configure `WHATSAPP_NUMBER` in `app.js` with the official business number (digits only, international format) once confirmed. Production checkout requires a secure backend, confirmed prices/inventory/delivery, payment verification, persisted customer orders and admin order controls.
